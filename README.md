# test_NIKE[나이키 쇼핑몰 웹 디자인]
애플리케이션 배포 시험 제출용 [웹 디자인 기획과 설명]

**NIKE**
*나이키*, 세계적인 유명 브랜드 브랜드의 상품 홍보와 판촉 효과를 목적으로 설계한 온라인 쇼핑몰 웹을 디자인.
웹 상단에 브랜드 파비콘 및 상품 시리즈 항목 설정.
브랜드사의 공식 광고 영상과 슬로건을 통해 브랜드의 가치를 적극적으로 홍보.
신제품과 베스트 셀러 인기 상품 등 대표적인 판매품들을 한눈에 볼 수 있도록 등록함.
상세 디자인을 확인할 수 있도록 마우스 커서 호버 시 상품이미지가 확대되는 효과를 적용.
